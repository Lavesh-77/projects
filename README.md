# projects
Quiz Application

A command-line quiz application built with Python and MySQL, designed as a practice project during JEE Mains preparation.

Features:

User login system with automatic new-user registration
Add custom multiple-choice questions (with 4 options and an answer key) to a persistent database
Take a randomized quiz — questions are shuffled each time for a fresh experience
Real-time scoring: +4 for correct answers, -1 for incorrect (JEE-style marking scheme)
Score persistence across sessions, tracked per user in the database
Simple menu-driven interface for navigating between quiz-taking and question-adding modes

Tech stack: Python, MySQL (via mysql-connector-python)

What I learned: Database design and connectivity with Python, CRUD operations, basic authentication logic, and building a persistent, stateful CLI application.
